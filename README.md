# Programación 1 · Trabajos prácticos en Python

Ejercicios del **TP1 de Programación 1** de la Tecnicatura Universitaria en Programación (UTN), organizados por tema.

| Carpeta | Tema | Contenido |
|---|---|---|
| `TP1_SECUENCIALES` | Estructuras secuenciales | Un programa con menú para ejecutar cada ejercicio: suma, doble de un número, área de un rectángulo y otros cálculos |
| `TP1_CONDICIONALES` | Estructuras condicionales | 10 ejercicios con `if / elif / else`; por ejemplo, determinar la estación del año según el hemisferio y la fecha |
| `TP1_REPETITIVAS` | Estructuras repetitivas | 5 ejercicios con `while` y `for`, como una caja de kiosco y un login con validación de datos |

## Cómo correr un ejercicio

```bash
python TP1_CONDICIONALES/ejercicio10.py
```

Requiere Python 3. No usa librerías externas.
